# AWDNS Provider

The AWDNS provider manages Authentic Web DNS hosted zones and records through
the AW external API. It authenticates with the OAuth2 client-credentials grant.

## Example Usage

```terraform
provider "awdns" {
  client_id     = var.awdns_client_id
  client_secret = var.awdns_client_secret
}
```

## Schema

### Required

- `client_id` (String) OAuth2 client ID for the AW external API.
- `client_secret` (String, Sensitive) OAuth2 client secret for the AW external API.

### Optional

- `base_url` (String) Base URL of the AW external API. Defaults to `https://api.authenticweb.com/external/v1`.
- `request_timeout` (Number) Per-request timeout in seconds. Defaults to 30. Reserved for a future SDK option; not yet enforced.
